# H100 Nemotron3 Super PR 5515 A/B Validation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Measure the functional and performance impact of M-LM PR #5515 for Nemotron3 Super HybridEP on multi-node CW-DFW H100.

**Architecture:** Run matched 32-node x 8-GPU H100 jobs from the existing Super performance recipe. The control uses the M-LM base containing #5008 and the #6114 expert-bias mask fix; the treatment cherry-picks only the #5515 router-mask implementation onto that exact base.

**Tech Stack:** NeMo-RL, Megatron-Bridge, Megatron-LM, DeepEP/HybridEP, Ray, Hydra, SLURM, CW-DFW H100

**Spec:** `docs/superpowers/plans/2026-08-27-h100-super-5515-ab.md`

## Global Constraints

- Use `examples/configs/recipes/llm/performance/grpo-nemotron3-super-120BA12B-32n8g.yaml` without model, batch, sequence, or topology changes.
- Use DeepEP commit `17cfb817bccec3a9c247013360cc550c2bac441e` from the checksum-pinned x86_64 wheel.
- Use 32 nodes, 8 H100 GPUs per node, EP=32, sequence packing, and NeMo-RL pre-padding.
- Run 20 steps with checkpointing disabled and W&B enabled for canonical metric extraction.
- Keep source under `/home`, node-local caches and venvs under `/raid/scratch`, and durable logs, images, model data, and immutable cache seeds under `/lustre`.
- Run `sbatch --test-only` before each actual submission and monitor running jobs for five minutes with at least 60 seconds between filtered scheduler checks.
