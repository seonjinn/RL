# SpecForge Qwen3 Drafter Matrix Stage 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build, train, export, and evaluate sixteen independent SpecForge DFlash/DSpark checkpoints for the pinned Qwen3-235B and Qwen3-30B Thinking targets on Open-PerfectBlend and the Red Hat public-drafter data family.

**Architecture:** A local, testable experiment controller owns immutable source pins, a sixteen-run matrix, dataset manifests, SpecForge config rendering, Slurm dependency graphs, artifact gates, and normalized evaluation records. Heavy target regeneration, training, export, vLLM serving, and NeMo-RL evaluation run on OCI-HSG first and Lyris only as a recorded fallback; local code is committed and pushed before the remote checkout submits anything.

**Tech Stack:** Python 3.11+, pytest, JSON/JSONL, PyYAML, Hugging Face datasets/hub, SpecForge `bdeb7d8aa77b616874ac46303fc2546739b61119`, SGLang capture, Mooncake, PyTorch distributed/FSDP, SLURM, vLLM 0.25.1 DSpark patch stack, NeMo-RL, GuideLLM-compatible HTTP benchmarks.

**Spec:** `docs/superpowers/specs/2026-08-17-specforge-qwen3-drafter-matrix-swe-rl-design.md`

## Global Constraints

- Stage 1 contains exactly `2 targets x 2 data families x 2 algorithms x 2 block sizes = 16` independently initialized checkpoints.
- Target revisions are Q235 `6cbffae6d8e28b986a6b17bd36f42f9fa0f1f0a5` and Q30 `144afc2f379b542fdd4e85a1fcd5e1f79112d95d`.
- SpecForge is pinned to `bdeb7d8aa77b616874ac46303fc2546739b61119`.
- Open-PerfectBlend is pinned to `af60f3c18201652a83a93f46fcfee1b646ba3df7`.
- Q235 Magpie is pinned to `1a982eea9ece373700dd8dfd04a4de08c2578c24`; Q30 Magpie to `523df96eb7474e97bca6f378b3baa372a4735fcc`; UltraChat to `8049631c405ae6576f93f445c6b8166f76f5505a`.
- The public benchmark is pinned to `RedHatAI/speculator_benchmarks@2ae86affa2cb97a972b7fc681dd51c04fbff083e` and each JSONL file is loaded independently.
- Every assistant response used for training is regenerated by the matching pinned target with Thinking enabled and the production chat template.
- DFlash and DSpark both use five dense draft layers; Q235 captures `[1, 23, 46, 68, 91]`, Q30 captures `[1, 12, 23, 34, 45]`.
- DFlash uses exponentially position-weighted cross-entropy only. DSpark uses CE 0.1 plus TV/L1 0.9, Markov rank 256, and confidence loss 1.0.
- Training block labels are B8 and B16. The renderer and GPU smoke must prove the corresponding actual proposal count; no code may infer vLLM `num_speculative_tokens` from a name alone.
- Physical vLLM KV-cache block size remains 16 for FlashAttention/Triton.
- OCI-HSG is primary; Lyris is fallback. GPU jobs use containers, scheduler preflight, logs under the experiment artifact tree, and five-minute post-submit monitoring.
- Math and SWE determine promotion. The nine-domain public suite is secondary comparability evidence.
- Stage 2 SWE continuation is out of scope for this plan and receives a separate plan only after Stage 1 baselines finish.
