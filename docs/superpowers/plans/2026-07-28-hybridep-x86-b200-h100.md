# HybridEP x86 B200 and H100 Validation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the latest HybridEP dependency and Qwen3-30B-A3B performance
configuration reproducible on x86_64, then validate and compare it on GCP-NRT
B200 and CW-DFW H100.

**Architecture:** Keep the existing NeMo-RL, Megatron-Bridge, and Megatron-LM
source baseline fixed. Update only the x86_64 DeepEP commit, add an inherited
4n8g HybridEP recipe and reusable profiles, build one immutable wheel per GPU
architecture, and run gated baseline-versus-HybridEP jobs on each cluster.

**Tech Stack:** Python 3.13, pytest, uv, YAML, Bash, Git, SLURM, Ray,
Megatron-Bridge, Megatron-LM, DeepEP, static HTML.
