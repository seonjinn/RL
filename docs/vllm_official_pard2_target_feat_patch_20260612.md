The corrected smoke launcher applies this patch to a fresh copied vLLM site, then runs an idempotent alias helper for `method=pard2`. It does not apply the broad `vllm_pard2_method_alias.patch` in the smoke path because that patch conflicted with the current vLLM source snapshot.

## What It Adds

- Routes `method=pard2` through `DraftModelProposer` with `pass_hidden_states_to_model=True`.
- Sizes the proposer target-feature buffer from `pard2_target_dim`, not draft hidden size.
- Enables auxiliary target hidden-state capture for PARD-2.
- Reads `pard2_target_layers` from the draft model config and normalizes negative layer IDs such as `-1`.
- Adds deferred Qwen3 draft-side `target_proj` creation from `pard2_target_dim` / `pard2_proj_bias` after normal draft checkpoint load.
- Loads `target_proj.*` weights from `warp_model.bin`.
- Adds projected and scaled PARD-2 target features to Qwen3 draft embeddings before the draft forward.
- Repeats the last target feature for PARD-2 parallel-drafting mask slots, matching the AMD PARD-2 inference path.
- Auto-detects PARD-2 when the draft config has `spd_type=pard2` or `pard2=true`.
