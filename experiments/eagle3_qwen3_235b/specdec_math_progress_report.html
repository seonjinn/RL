Dataset Contract

The clean Speculators run trains on non-OpenMath mixed math data and evaluates in NeMo-RL on OpenMath. The actual NeMo-RL test file, openmath_reasoning_cot_conversations_50k.jsonl, is used as a denylist before the 500K training file is written, so direct prompt leakage is excluded in the current exact-unique build.

1. Prompt pool

500K non-OpenMath math prompts from NuminaMath-1.5, NuminaMath-CoT, OpenThoughts-114k, math-deepscaler, and DAPO-Math-17k.

2. Target responses

30B target responses are complete for the 500K path. 235B responses are still separate and not merged into this training corpus.

3. Speculators format

Convert exact-unique conversations into Speculators JSONL, then tokenized Arrow data.

4. Hidden states

Extract selected target-model hidden states for Eagle3. This is the current storage and runtime bottleneck.

5. Train + evaluate

Train the Eagle3 drafter, then measure NeMo-RL acceptance and generation tok/s/GPU on the OpenMath eval file.

Train/Test Split Summary

QuestionCurrent Answer
What is the current drafter training data? For the clean 30B path, the training pool is mixed non-OpenMath math: NuminaMath-1.5, NuminaMath-CoT, OpenThoughts-114k, math-deepscaler, and DAPO-Math-17k. Target responses are synthesized with Qwen/Qwen3-30B-A3B, then converted to Speculators Eagle3 training data.
What is the actual NeMo-RL test set? NeMo-RL rollout throughput and acceptance tests use openmath_reasoning_cot_conversations_50k.jsonl. It contains 50000 rows and 44304 unique normalized prompts. This file is the evaluation/test prompt source for the baseline and SpecDec NeMo-RL runs.
Does the mixed 500K training set overlap the NeMo-RL test set? No exact prompt-level overlap in the current exact-unique build. The OpenMath NeMo-RL evaluation prompts are loaded as a denylist before writing training rows. The denylist size is 44304, and the final merge/validation path reports records_written=500000, duplicate_prompts=0, and denylisted_prompts=0 for the final training file.
Which result has an OpenMath caveat? The older 30B OpenMath-trained SpecDec result, 1.17x-1.22x, is useful as an integration proof, but it is not the leakage-clean final claim. The clean comparison is mixed non-OpenMath training evaluated on OpenMath NeMo-RL prompts.
What is not mixed into the 500K clean set? The OpenMath NeMo-RL evaluation file is not used as a training source. Public HF Eagle3 checkpoints are also separate evaluation inputs, not part of this Speculators 500K training corpus.
What is the unit of uniqueness? User prompts are normalized by lowercasing and collapsing whitespace, then used as the uniqueness and denylist key. Assistant responses are target-model generations and are not used to decide train/test overlap.

CheckEvidenceInterpretation

OpenMath denylist denylist_prompt_count=44304 from openmath_reasoning_cot_conversations_50k.jsonl. NeMo-RL evaluation prompts are reserved before any training row is written.
Training/eval overlap Final validation: rows=500000, valid=500000, unique_user_prompts=500000, duplicate_prompts=0, denylisted_prompts=0. No normalized OpenMath evaluation prompt appeared in the final mixed training inputs.
Internal duplicates skipped_duplicate_or_seen=59, then 59 fresh DAPO replacements were appended. The final file is exactly 500K prompt-unique training conversations.
Remaining caveat The check is prompt-level lexical normalization, not a semantic near-duplicate search. It prevents direct leakage; it does not claim that mathematically similar problems never occur across datasets.
