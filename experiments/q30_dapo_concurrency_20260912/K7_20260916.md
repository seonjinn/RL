# DAPO 40K K7 extension

Add frozen DFlash K7 and DSpark K7 at S64/S128, 20 policy steps per arm.
Reuse New Draft Base B8 exported-checkpoint-44000 checkpoints from the K5
cohort. Keep DAPOMath17K, GBS2048 (128 x 16), 2048 input / 38912 response /
40960 total token caps, eight four-GB200 nodes, training TP2/EP8/CP4,
generation TP1, BF16, flashinfer_trtllm, FAP, and all loss/sampling settings.
This is the existing DAPO adaptation, not the unmodified OpenMath recipe.

Only K, graph shapes and identifying metadata differ from the corresponding
K5 arm. DFlash target/draft query width is 8; DSpark target width is 8 and
anchor-as-first draft width is 7. Geometric request buckets preserve the K5
methodology, covering all request counts with at most 2x padding:

| Arm | Limit | Target terminal query tokens | Draft terminal query tokens |
|---|---:|---:|---:|
| DFlash K7 | 64 | 512 | 512 |
| DFlash K7 | 128 | 1024 | 1024 |
| DSpark K7 | 64 | 512 | 448 |
| DSpark K7 | 128 | 1024 | 896 |

These are decode query counts, not context lengths. FAP configuration and
bucket-envelope tests do not certify runtime replay or complete prefill
coverage. The engine can receive only 64 samples under equal sharding of the
2048-sample batch, so S128 may be nonbinding. No topology changes are made to
force 128 concurrent requests.

Use exact W&B Steps 3–20, report generation/E2E throughput and walltime,
acceptance, generated length, reward, entropy, truncation, generation KL,
policy KL mean/median/max/spike steps and token probability-ratio diagnostics.
Existing DSpark K5 S128 has a large policy KL spike (step18:25278.11); baseline
also has spikes. These runs are performance/correctness investigations, not
quality-certified recipes. Do not discard spikes or infer accuracy equivalence
from similar mean reward.

Launch from the synchronized source worktree, after test-only checks:

```bash
export Q30_DAPO47K_MAX_STEPS=20
for arm in dflash_k7 dspark_k7; do
  for seqs in 64 128; do
    bash experiments/q30_dapo_concurrency_20260912/submit.sh --submit "$arm" "$seqs"
  done
done
```

Each job is independent, eight-hour batch_long, no online draft training and no
checkpointing, matching K5. Baseline default and K5 measurements already
completed; matched S64/S128 baseline controls are jobs7186075/7186077. No new
baseline duplicates are needed. No NeMo-RL runtime files change.
