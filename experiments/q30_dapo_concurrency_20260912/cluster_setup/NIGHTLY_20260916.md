## Initial smoke root cause and corrected verification

Both images were staged and passed SHA256, driver imports and four-GPU Megatron
execution. Jobs3078480/2837270 then failed because our smoke directly imported
`vllm._C`. Read-only inspection of both immutable images confirmed their vLLM
0.25.1 package instead ships `_C_stable_libtorch.abi3.so`, and its own
`vllm/platforms/cuda.py` imports `vllm._C_stable_libtorch`. This is a smoke-test
assumption error, not evidence of missing CUDA binaries or a main-merge failure.

Correct the smoke to import `current_platform` from `vllm.platforms`, verify CUDA
selection, and run GPU checks in both generation environments. Unset
PYTHONOPTIMIZE so assertions cannot be disabled. Reuse the immutable downloaded
images with a checksum check; do not reinstall packages or download again.
`recheck_nightly.sbatch` only publishes the dedicated validation link after pass.
Next gate is a no-SpecDec 1-step recipe, using native image source and recording
its provenance independently of the host launcher. OCI runtime is untouched.
