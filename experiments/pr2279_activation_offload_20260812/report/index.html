Root cause and solution

GRPO runs current/reference logprob before policy training. The pre-fix no_grad, forward_only pass initialized and reset MCore's one-time offload warmup without a backward graph, freezing an empty layout. This exactly explains the all-rank 0.00-MB summary.

The final fix suspends config-controlled initialization during every forward-only phase. If a real training warmup already created the singleton, it also suspends the existing manager and cached chunks, then restores the prior state in finally. VPP configs are fully discovered and deduplicated before mutation. A cached MoE hook may create an empty singleton during the first logprob, but it remains warm with zero cached chunks so the first policy forward/backward can initialize the real layout.
